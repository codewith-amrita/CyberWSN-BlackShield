# CyberWSN-BlackShield

## Project Description
NS-3 based simulation of Blackhole Attack in Wireless Sensor Networks (WSN).

## Features
- Normal WSN simulation using AODV
- Blackhole attack simulation
- Packet loss behavior analysis

## How to Run

### Normal Simulation
./ns3 run scratch/clean-wsn

### Blackhole Attack Simulation
./ns3 run scratch/blackhole-attack
